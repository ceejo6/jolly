==============================================================================
             Jolly: First-Time Setup & Deployment Guide 🍿
==============================================================================

This guide walks you through setting up and running Jolly on a dedicated
physical machine running Ubuntu 24.04 Server.


------------------------------------------------------------------------------
Prerequisites Checklist
------------------------------------------------------------------------------

Before you start, make sure you have:
1. A physical computer with Ubuntu 24.04 LTS Server installed.
2. An active internet connection connected via Ethernet.
3. Access to the command line (either directly via keyboard/monitor on the
   machine or over SSH).


------------------------------------------------------------------------------
One-Shot Automated Deployment
------------------------------------------------------------------------------

Copy the single command below, paste it into your Ubuntu terminal, and press Enter:

----------
curl -fsSL https://raw.githubusercontent.com/ceejo6/jolly/main/install.sh | sudo bash
----------

What this command does automatically:
1. Installs Git, Docker Engine, and Compose plugins.
2. Clones Project Jolly directly to /opt/jolly.
3. Configures hardware acceleration for Intel Quick Sync Video.
4. Connects systemd (jolly.service) so the server auto-boots on power loss.
5. Runs the complete test harness to verify health.
6. Prints the exact browser URL to open on your phone or laptop.


------------------------------------------------------------------------------
Open Jellyfin in Your Web Browser
------------------------------------------------------------------------------

When the installer finishes, look at the terminal. It will print your link:
Example: http://192.168.1.150:8096

1. Go to your personal computer, laptop, or phone connected to the same Wi-Fi.
2. Open your web browser (Chrome, Safari, Firefox, Edge).
3. Type the URL printed by the installer into the address bar.
4. Follow the Jellyfin wizard:
   - Preferred Language -> Next.
   - Set admin Username and Password -> Next.
   - Add Media Library:
     * Content Type: Movies
     * Folder: Select /media/movies
     * Check "Nfo" under Metadata Savers.
     * Check "Save artwork into media folders".
     * Click OK.
   - Remote Access: Leave "Allow remote connections" checked, uncheck "Enable UPnP".
   - Click Finish.


------------------------------------------------------------------------------
How to Add Real Movies and TV Shows
------------------------------------------------------------------------------

Place video files in their respective folders on the server:

Movies:   /opt/jolly/data/media/movies/
TV Shows: /opt/jolly/data/media/tv/

Example Folder Structure:
/opt/jolly/data/media/
├── movies/
│   └── Interstellar (2014)/
│       └── Interstellar (2014).mkv
└── tv/
    └── Breaking Bad (2008)/
        └── Season 01/
            ├── Breaking Bad - S01E01.mkv
            └── Breaking Bad - S01E02.mkv

To refresh your library:
In your Jellyfin web interface, open Dashboard -> Libraries -> click the
three dots on Movies -> Scan Library.


------------------------------------------------------------------------------
Useful Day-to-Day Commands
------------------------------------------------------------------------------

All commands should be run from inside /opt/jolly:

Check server health and service status:
----------
sudo systemctl status jolly.service
----------

Restart the media stack:
----------
sudo systemctl restart jolly.service
----------

Stop the media stack:
----------
sudo systemctl stop jolly.service
----------

View live system logs:
----------
sudo docker compose logs -f
----------

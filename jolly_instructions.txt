==============================================================================
             Jolly: First-Time Setup & Deployment Guide 🍿
==============================================================================

This guide walks you through setting up and running Jolly on a dedicated
physical machine running Ubuntu 24.04 Server.


------------------------------------------------------------------------------
Prerequisites Checklist
------------------------------------------------------------------------------

Before you start, make sure you have:
1. The target server PC (e.g., Intel i5-8400 machine).
2. A temporary monitor (HDMI/DisplayPort) and USB keyboard.
3. An active internet connection connected via an Ethernet cable.
4. A USB flash drive with Ubuntu 24.04 LTS Server installer.
5. A primary laptop or desktop connected to the same home Wi-Fi/network.


------------------------------------------------------------------------------
Phase 1: Initial OS Installation & SSH Setup (Temporary Monitor)
------------------------------------------------------------------------------

1. Connect the target server to the temporary monitor, USB keyboard, power,
   and the Ethernet cable.
2. Insert your Ubuntu 24.04 Server USB installer and power on the machine.
3. Follow the on-screen installer prompts:
   - Language & Keyboard layout: Select your defaults.
   - Network connections: Ensure the Ethernet interface receives an IP.
   - Storage configuration: Use entire disk (default).
   - Profile setup: Choose a server name, username, and password.
     (Remember this username and password; you will need it to SSH in).
   - SSH Setup (CRITICAL):
     When prompted with "SSH Setup", check the box:
     [*] Install OpenSSH server
   - Featured Server Snaps: Leave unselected -> Finish installation.
4. Once installation completes, reboot the server and unplug the USB installer.
5. Log into the server using your keyboard and created credentials.
6. Find and write down your Server IP address by running:

----------
hostname -I | awk '{print $1}'
----------

Example output: 192.168.1.150

7. (Headless Transition):
   You can now unplug the monitor cable and USB keyboard from the server.
   The server only needs its power cord and Ethernet cable connected.


------------------------------------------------------------------------------
Phase 2: Connect via SSH from Your Main Computer
------------------------------------------------------------------------------

Go to your primary laptop or desktop (Windows, Mac, or Linux):

1. Open PowerShell, Terminal, or Command Prompt.
2. Connect to the server using the username you created and the Server IP:

----------
ssh your_username@192.168.1.150
----------

(Replace "your_username" with your actual user, and "192.168.1.150" with the
IP you noted down in Phase 1).

3. Type "yes" when asked to accept the host key fingerprint, then enter
   your password. You are now inside the server's command line.


------------------------------------------------------------------------------
Phase 3: One-Shot Automated Deployment
------------------------------------------------------------------------------

Copy the single command below, paste it into your SSH terminal, and press Enter:

----------
curl -fsSL https://raw.githubusercontent.com/ceejo6/jolly/main/install.sh | sudo bash
----------

What this command does automatically:
1. Installs Git, Docker Engine, and Compose plugins.
2. Installs and configures Samba for Windows drag-and-drop media sharing.
3. Clones Project Jolly directly to /opt/jolly.
4. Configures hardware acceleration for Intel Quick Sync Video.
5. Connects systemd (jolly.service) so the server auto-boots on power loss.
6. Runs the complete test harness to verify health.
7. Prints your web streaming link and Windows network share path.


------------------------------------------------------------------------------
Phase 4: Open Jellyfin in Your Web Browser
------------------------------------------------------------------------------

When the installer finishes, look at the terminal. It will print your link:
Example: http://192.168.1.150:8096

1. Open your web browser (Chrome, Safari, Firefox, Edge).
2. Type the URL printed by the installer into the address bar.
3. Follow the Jellyfin wizard:
   - Preferred Language -> Next.
   - Set admin Username and Password -> Next.
   - Add Media Library:
     * Content Type: Movies
     * Folder: Select /media/movies
     * Check "Nfo" under Metadata Savers.
     * Check "Save artwork into media folders".
     * Click OK.
   - Remote Access: Leave "Allow remote connections" checked, uncheck "Enable UPnP".
   - Click Finish.


------------------------------------------------------------------------------
Phase 5: How to Add Movies and Shows from Windows (Drag & Drop)
------------------------------------------------------------------------------

You do not need to use the terminal to upload videos. You can drag and drop
files directly from your Windows desktop or laptop:

1. On your Windows PC, press the keyboard shortcut: Win + R
2. Type your server's network address and hit Enter:
   \\<server-ip>\JollyMedia
   (Example: \\192.168.1.150\JollyMedia)

3. When Windows prompts you for network credentials, sign in with:
   - Username: jollyadmin
   - Password: jollysecure123
   *(Check "Remember my credentials" so it connects automatically next time)*

4. A Windows folder will open displaying "movies" and "tv".
5. Drag and drop any movie into the "movies" folder.
   Recommended format:
   movies\Interstellar (2014)\Interstellar (2014).mkv

6. Refresh your library:
   In your Jellyfin web interface (http://<server-ip>:8096), go to:
   Dashboard -> Libraries -> click the three dots on Movies -> Scan Library.
   The movie will appear on your phone, PC, and TV immediately.


------------------------------------------------------------------------------
Useful Day-to-Day Commands
------------------------------------------------------------------------------

All commands should be run from inside /opt/jolly:

Check server health and service status:
----------
sudo systemctl status jolly.service
----------

Restart the media stack:
----------
sudo systemctl restart jolly.service
----------

Stop the media stack:
----------
sudo systemctl stop jolly.service
----------

View live system logs:
----------
sudo docker compose logs -f
----------
